ブラウザで動く仮想マシン — インストール不要、タブの中で本物のOSが起動します

新しいマシンを追加

OSをインストールする場合は「空のHDD」を追加してください（CD-ROM接続のとき有効です）。 Windows 98 / ME などのセットアップで「ハードディスクがない」と出るのは、HDDが接続されていないためです。 空のHDDは未使用領域なので、セットアップ中にパーティション作成やフォーマットを求められたら、そのまま進めてください。 インストール後はマシンの「💽 HDDを保存」からディスクイメージをダウンロードでき、次回はそのファイルを「ハードディスク（IMG向け）」で読み込むと続きから使えます。

よくある質問

きつね仮想とは何ですか？

きつね仮想 — エンジン: v86（x86 エミュレーター / WebAssembly）。計算はすべてあなたのブラウザの中で行われ、データはサーバーに送信されません。インストールも登録も不要で、開いたタブの中で本物のOSが起動します。

64bit実験モードとは何ですか？

通常モードのエンジン（v86）は32bit専用のため、64bit CPUに対応した別エンジン（v64）を使う実験モードです。Alpine Linux 64bit がそのまま起動できるほか、自分の64bitイメージ（ISOなど）も読み込めます。起動に時間がかかる場合があり、RAMは512MB以上がおすすめです。安定性重視なら通常モードを使ってください。

500GBのハードディスクが選べますか？

64bit実験モードで自分のイメージを起動するとき、「空のHDD 500 GB（スパース）」が選べます。スパース形式（qcow2）なので、ファイル自体は小さく、仮想マシンからは500GBのディスクとして見えます。書き込んだ内容はメモリ上に保持されるため、電源を切ると消えます。大事なデータは残さないでください。

画面キーボードはありますか？

各マシンの「⌨ キーボード」ボタンを押すと、Windows風の画面キーボードが開きます。スマホやタブレットでの入力に便利です。Shift / Ctrl / Alt / ⊞ キーは押すと保持され、次のキーと組み合わせて送られます（1回入力すると解除されます）。

データはサーバーに送られますか？

送られません。仮想マシンはあなたのブラウザの中で動き、読み込んだイメージファイルや仮想ハードディスクの内容が外部に送信されることはありません。
