ブラウザで動く仮想マシン — インストール不要、タブの中で本物のOSが起動します

新しいマシンを追加

OSをインストールする場合は「空のHDD」を追加してください（CD-ROM接続のとき有効です）。 Windows 98 / ME などのセットアップで「ハードディスクがない」と出るのは、HDDが接続されていないためです。 空のHDDは未使用領域なので、セットアップ中にパーティション作成やフォーマットを求められたら、そのまま進めてください。 インストール後はマシンの「💽 HDDを保存」からディスクイメージをダウンロードでき、次回はそのファイルを「ハードディスク（IMG向け）」で読み込むと続きから使えます。

対応の目安：Linux（32bit）・FreeDOS・KolibriOS は同梱イメージですぐ起動します。 Windows は 98 / 2000 / XP のような古い32bit版が、自分の正規イメージを使う場合のみ対象です（Windows 10 / 11 はブラウザエミュレーションでは動きません）。 ReactOS は Windows 互換の無料OSで、ISOを読み込めます。 Android は v86 エンジンでは公式に「まともに動作しない」とされているため実験扱いです（Android-x86 の古いISOでシェルが出る程度の場合があります）。 イメージの配布はしません。権利のあるファイルだけを使ってください。

よくある質問

きつね仮想とは何ですか？

きつね仮想 — エンジン: v86（x86 エミュレーター / WebAssembly）。計算はすべてあなたのブラウザの中で行われ、データはサーバーに送信されません。インストールも登録も不要で、開いたタブの中で本物のOSが起動します。

どのOSが動きますか？

同梱の Linux / Linux 3 / KolibriOS / FreeDOS はそのまま起動します。Windows 98 / 2000 / XP や ReactOS は、自分のイメージファイル（.iso / .img）を読み込めば起動できます。Windows 10 / 11 など64bitのOSは動きません。Android は実験扱いで、まともに動作しない場合があります。

Windowsのセットアップで「ハードディスクがない」と言われます

仮想ハードディスクが接続されていないためです。自分のイメージから起動するときに「仮想ハードディスク」で「空のHDD」を選んでから起動し直してください。空のHDDは未使用領域なので、セットアップ中にパーティションの作成やフォーマットを求められたら、そのまま進めてください。インストール後は「💽 HDDを保存」でディスクをファイルに保存でき、次回はそのファイルをハードディスクとして読み込めます。

マウスカーソルが自分のカーソルと合いません

画面をクリックするか、マシンの「🖱 マウスを合わせる」ボタンを押してください。マウスが画面の中にロックされ、仮想マシン内のカーソルと動きが合うようになります。ロックの解除は Esc キーです。

データはサーバーに送られますか？

送られません。仮想マシンはあなたのブラウザの中で動き、読み込んだイメージファイルや仮想ハードディスクの内容が外部に送信されることはありません。
