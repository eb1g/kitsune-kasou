対応の目安：Linux（32bit）・FreeDOS・KolibriOS は同梱イメージですぐ起動します。 Windows は 98 / 2000 / XP のような古い32bit版が、自分の正規イメージを使う場合のみ対象です（Windows 10 / 11 はブラウザエミュレーションでは動きません）。 ReactOS は Windows 互換の無料OSで、ISOを読み込めます。 Android は v86 エンジンでは公式に「まともに動作しない」とされているため実験扱いです（Android-x86 の古いISOでシェルが出る程度の場合があります）。 イメージの配布はしません。権利のあるファイルだけを使ってください。

きつね仮想 — エンジン: v86（x86 エミュレーター / WebAssembly）。計算はすべてあなたのブラウザの中で行われ、データはサーバーに送信されません。

元になったサイト: BoxLinuxFarm（FarmSub） と同じ v86 系の仕組みを使っています。
